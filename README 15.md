# Управление активами компании

## Описание проекта
Данный проект представляет собой реляционную базу данных для информационной системы учета материальных и нематериальных активов предприятия. База данных разработана для Microsoft SQL Server и предназначена для централизованного хранения информации об активах, их категориях, местах расположения, ответственных сотрудниках, документах, амортизации, переоценке, техническом обслуживании, инвентаризации и перемещениях между подразделениями.

Система поддерживает разграничение прав доступа по ролям:
- **Пользователь** — просмотр данных и отчетов;
- **Менеджер** — управление активами, документами, техническим обслуживанием и инвентаризацией;
- **Администратор** — полный доступ к структуре и данным базы.

## Описание предметной области
Предметная область проекта — **управление активами компании**.

В базе данных учитываются следующие сущности:
- **Активы** — оборудование, мебель, техника, программное обеспечение, лицензии и другие материальные и нематериальные ценности;
- **Категории активов** — основные средства, нематериальные активы, МПЗ, серверное оборудование, сетевое оборудование и другие категории;
- **Места расположения** — офисы, склады, цеха, лаборатории, архивы и виртуальные площадки;
- **Ответственные сотрудники** — работники предприятия, за которыми закреплены активы;
- **Документы** — акты приема-передачи, гарантийные талоны, договоры, спецификации, отчеты по амортизации;
- **Амортизация и переоценка** — учет изменения стоимости активов;
- **Техническое обслуживание** — планы и фактические события обслуживания;
- **Инвентаризация** — сессии проверки наличия и состояния активов;
- **Перемещения** — контроль перевода активов между подразделениями и локациями.

Основной бизнес-смысл проекта заключается в автоматизации учета активов предприятия, контроле их состояния, местоположения, стоимости и обслуживающих процессов.

## Тестовые данные
В базе данных автоматически создаются тестовые данные:
- 120 записей в таблице `assets`;
- не менее 20 записей в ключевых таблицах-справочниках;
- документы, амортизация, переоценка, планы ТО, события ТО, инвентаризация и перемещения.

Это позволяет проверить корректность связей, запросов и работоспособность всей системы.

## Обновление для практической работы №15
В структуру базы данных добавлена поддержка хранения изображений в бинарном формате (**BLOB**). Для этого в ключевую таблицу `assets` добавлено поле:

- `image VARBINARY(MAX)` — основное изображение актива.

Каждая тестовая запись в таблице `assets` теперь содержит заполненное бинарное поле `image`. В учебной версии проекта в это поле записываются тестовые бинарные данные, имитирующие изображение актива. Такой подход позволяет проверить:
- корректность структуры таблицы;
- хранение BLOB-данных в SQL Server;
- выборку записей с мультимедийными данными;
- готовность базы к последующей интеграции с клиентским приложением.

### Проверка BLOB-данных
После выполнения скрипта можно проверить наличие бинарных изображений следующими запросами:

```sql
SELECT COUNT(*) AS assets_with_image
FROM asset_mgmt.assets
WHERE image IS NOT NULL;

SELECT TOP 10
    asset_code,
    asset_name,
    DATALENGTH(image) AS image_size_bytes
FROM asset_mgmt.assets;
```

Ожидаемый результат: все 120 записей в таблице `assets` должны содержать заполненное поле `image`.
