# Управление активами компании — WPF-приложение

## Описание выполненной работы
В проекте реализована клиентская часть информационной системы для предметной области «Управление активами компании». Приложение разработано на WPF и использует базу данных SQL Server `AssetManagementDB`.

В рамках практической работы №18 добавлены:

- ролевая модель с ролями **Пользователь**, **Менеджер**, **Администратор**;
- сохранение текущей роли после авторизации;
- условная видимость элементов интерфейса на странице каталога:
  - **Пользователь** видит только карточки каталога;
  - **Менеджер** видит карточки и все CRUD-кнопки;
  - **Администратор** видит карточки, CRUD-кнопки и кнопку **«Админ-панель»**;
- кнопка **«Выйти»** с возвратом на страницу авторизации;
- страница **AdminPanelPage.xaml** с двумя вкладками:
  - **Управление пользователями** — список пользователей, поиск, смена роли, блокировка и разблокировка;
  - **Системная аналитика** — общее число активов, статистика по категориям, топ-5 последних активов, статистика по ролям пользователей.

### Инструкция по тестированию ролей
Приложение поддерживает два режима тестирования:

#### 1. Через SQL Server
Строка подключения по умолчанию:

```csharp
Server=(local)\SQLEXPRESS;Database=AssetManagementDB;Trusted_Connection=True;TrustServerCertificate=True;
```

Логины из БД:
- `login01`, `login02` — администраторы
- `login03` ... `login08` — менеджеры
- `login09` ... `login20` — пользователи

Пароль в учебном проекте используется как проверка непустого ввода.

#### 2. Демонстрационный вход без БД
Если база временно недоступна, можно войти так:
- `admin / admin`
- `manager / manager`
- `user / user`

### Изменения в БД для роли администратора
Для поддержки блокировки пользователей в таблицу `asset_mgmt.system_users` добавлено поле:

```sql
is_blocked BIT NOT NULL DEFAULT 0
```
