# Управление активами компании — Практическая работа №16

## Описание выполненной работы
Реализована страница `CatalogPage.xaml` для отображения основной сущности в виде карточек. Для вывода используется `ListView` с `WrapPanel`. Каждая карточка показывает изображение из BLOB-поля `image`, название актива, категорию, статус, местоположение и краткое описание. После успешного входа и демонстрационной регистрации пользователь переходит на страницу каталога.

Загрузка каталога выполняется из SQL Server `AssetManagementDB`. Если подключение к БД недоступно, приложение показывает демонстрационные карточки.
