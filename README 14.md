# Управление активами компании — интерфейс авторизации и регистрации

## Описание выполненной работы

В рамках практической работы №14 разработана клиентская часть информационной системы для предметной области **«Управление активами компании»** на базе WPF-приложения в Visual Studio.

В проекте реализованы:

- окно авторизации `LoginPage.xaml`;
- окно регистрации `RegistrationPage.xaml`;
- единый фирменный стиль приложения;
- логотип в формате `.png`;
- иконка проекта в формате `.ico`;
- централизованное хранение цветов, шрифтов и стилей в `App.xaml`;
- обработчики перехода между страницами;
- проверка совпадения пароля и подтверждения пароля;
- вывод сообщения **«Регистрация в разработке»**.

Цветовая схема приложения соответствует варианту 9:

- цвет фона: `#FFECEFF1`;
- акцентный цвет: `#FF37474F`;
- дополнительный цвет: `#FF00897B`;
- шрифт: `Arial`.

Приложение оформлено в корпоративном стиле и может служить основой для дальнейшего подключения к базе данных из практической работы №13.

## Состав проекта

- `App.xaml` — глобальные ресурсы, стили, цвета и шрифты;
- `MainWindow.xaml` — главное окно с `Frame` для навигации;
- `Pages/LoginPage.xaml` — страница авторизации;
- `Pages/RegistrationPage.xaml` — страница регистрации;
- `Assets/logo.png` — логотип приложения;
- `Assets/app.ico` — иконка приложения.
