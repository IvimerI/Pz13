# Управление активами компании — Практическая работа №17

## Описание выполненной работы
В WPF-приложение добавлены CRUD-операции для каталога активов: создание, чтение, редактирование и удаление записей. На странице каталога реализованы поиск, фильтрация по категории и статусу, сортировка по нескольким полям и направление сортировки. Создана страница `AddEditPage.xaml` для добавления и редактирования записей, загрузки изображения с диска и просмотра превью.

Строка подключения в сервисе настроена под SQL Server:
`Server=(local)\SQLEXPRESS;Database=AssetManagementDB;Trusted_Connection=True;TrustServerCertificate=True;`
